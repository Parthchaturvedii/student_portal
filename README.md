Student Portfolio is a full-stack web application designed to showcase academic details, technical skills, and projects through a clean and responsive interface.

The frontend is built using HTML, CSS, JavaScript, and React, focusing on responsive design and smooth user experience. It is deployed on Vercel for fast and reliable hosting.

The backend is developed using Node.js and Express.js to handle API requests, form submissions, and data management. It is deployed on Render for scalable server-side operations.

The database uses MongoDB to securely store contact messages and portfolio data.

This project demonstrates REST API integration, deployment workflow, and full-stack development practices with real-world hosting platforms.
